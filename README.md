# Agencia KE
Monte seu orçamento na Agência KE de forma rápida e personalizada. O cliente escolhe os serviços que deseja, define as quantidades e o sistema calcula automaticamente o subtotal, os descontos e o valor final. A partir de 6 unidades contratadas, o cliente recebe 20% de desconto. A solicitação é enviada diretamente para o WhatsApp da Agência KE.
